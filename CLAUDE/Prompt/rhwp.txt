   - 포트: 8001 (내부망)

3. README에 단독 실행/테스트 방법 추가

## 파싱 알고리즘 (사전 분석 결과)
- pyhwp의 `hwp5html --output {dir} {file}` 명령으로 XHTML 변환
- BeautifulSoup으로 최상위 table.TableControl 추출 (보통 3개)
  - 테이블 #1: 결제란 (담당 셀에서 teacherName 추출)
  - 테이블 #2: 본문 (14행, 메타정보 + 시간대별 활동) ★ 핵심
  - 테이블 #3: 방과후 (특성화/간식/자유놀이)
- 테이블 #2 행 0의 셀들에서 라벨(일시/학급명/수업시간/수업일수)과 값을 가로로 페어링
- 행 1부터: 첫 셀 = label, 두 번째 셀 = content
- "몬테소리 자유놀이" 셀 내부의 중첩 table을 별도 추출해 montessoriRecords로

## category 매핑 (label → category)
- 등원, 출석 → MORNING
- 나침반 안전교육, 안전, 화재대피 → SAFETY  
- 점심, 식사 → LUNCH
- 바깥놀이, 운동장 → OUTDOOR
- 평가, 일일평가 → EVALUATION
- 그 외 → OTHER

## 검증 기준

  subject=경청, classNameRaw=열성반, sections 11개 이상, 
  montessoriRecords 17개 이상 추출
- samples/hwp/CASE_5_26.hwp도 같은 알고리즘으로 정상 추출

## 주의사항
- 실패 시 명확한 에러 메시지 (어느 행에서 어떤 패턴 못 찾았는지)
- 라벨 텍스트는 공백 정규화 후 매칭 (예: "일  시" → "일시")
- 다른 양식에 대비해 라벨 매칭은 부분일치 허용 (예: "수업시간"이 들어가면 됨)
